An open-source toolkit for Tamil and code-mixed Tanglish text: phonetic transliteration, reversible romanization, word-level language detection and Tamil letter analysis. Zero dependencies. Everything on this page runs in your browser.

npm install github:Saffiya-7/tanglish-kit
    Word-level language detection Tanglish English Tamil

    Character n-gram Naive Bayes + neighbour smoothing. Hover a word to see confidence.

      Use it in code

      import { tanglishToTamil, tamilToTanglish, tagWords, splitLetters } from 'tanglish-kit';

tanglishToTamil('vanakkam nanba');                 // 'வணக்கம் நண்பா'
tanglishToTamil('meeting cancel aachu', { keepEnglish: true });
                                                  // 'meeting cancel ஆச்சு'
tamilToTanglish('நன்றி');                          // 'nandri'
tagWords('office ku late').map(t => t.lang);       // ['en', 'tanglish', 'en']
splitLetters('தமிழ்');                              // ['த', 'மி', 'ழ்']  (not 5!)

      Also a CLI: tanglish "vanakkam" · -r reverse · -t tag words · -l letters · -e keep English
