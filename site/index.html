Tamil NLP for the way people actually type.

Millions of people write Tamil in English letters, mixed with English words. tanglish-kit converts it to தமிழ், tells the languages apart word by word, and counts Tamil letters correctly. It's tiny, typed, and runs entirely in the browser.

      Features

      Everything Tamil text pipelines usually get wrong

      அ

      Phonetic transliteration

      Context rules for ந/ன/ண, ங்க, ஞ்ச, ற்ற and glides, plus a lexicon of common chat words: vanakkam → வணக்கம்.

      Code-mix aware

      A trained model tags each word as Tanglish, English or Tamil, so meeting cancel aachu keeps the English intact.

      Reversible romanization

      Casual output that reads like real Tanglish, or a precise scheme that converts back to exactly the same Tamil text.

      மி

      Letter-correct counting

      "தமிழ்".length is 5, but it has 3 letters. Split, count and classify உயிர் / மெய் / உயிர்மெய் properly.

      Tiny & offline

      Zero runtime dependencies. The whole library, model included, is 77 KB minified (24 KB gzipped), and it needs no server or API key.

      TypeScript + CLI

      Fully typed API for Node and browsers, plus a tanglish command for scripts and piping files.

      How it works

      A small, honest model, measured

      No black box: a character n-gram Naive Bayes classifier you can retrain with one command.

      1. 1

        Tokenize

        Split into Latin, Tamil-script, number and punctuation runs, keeping offsets.

        office ku late
      2. 2

        Score each word

        Character 1–4-grams (^ku, ce$…) go through Naive Bayes to get Tanglish-vs-English log-odds.

        …
      3. 3

        Smooth with context

        Languages switch in runs, so uncertain short words lean toward their neighbours.

        …
      4. 4

        Transliterate

        Tanglish words go through the lexicon, then the phonetic rules. English is left as-is.

        …

      Sentence accuracy is measured on hand-labelled code-mixed sentences after removing every one of their words from training. The data set is small (about 1,100 words), so treat these as rough numbers. See the data →

      Up and running in a minute

      Install from GitHub, import what you need. Types are included.

      FunctionWhat it does
      tanglishToTamil(text, opts?)Tanglish → Tamil script
      tamilToTanglish(text, opts?)Tamil → Tanglish, casual or precise
      tagWords(text)Per-word language + confidence + offsets
      detectLanguage(text)Language shares, dominant, code-mixed?
      splitLetters(text)Real Tamil letters (graphemes)
      analyzeText(text)Letter-type statistics
       
      import { tanglishToTamil, tamilToTanglish, tagWords } from 'tanglish-kit';

tanglishToTamil('vanakkam nanba');
// → 'வணக்கம் நண்பா'

tanglishToTamil('meeting cancel aachu', { keepEnglish: true });
// → 'meeting cancel ஆச்சு'

tamilToTanglish('நன்றி');
// → 'nandri'

tagWords('office ku late').map((t) => t.lang);
// → ['en', 'tanglish', 'en']
      # Tanglish → Tamil
tanglish "vanakkam nanba"

# Tamil → Tanglish (add -p for precise)
tanglish -r "நன்றி"

# keep English words
tanglish -e "meeting cancel aachu"

# tag words, or convert a whole file
tanglish -t "office ku late"
cat chat.txt | tanglish > chat.ta.txt
